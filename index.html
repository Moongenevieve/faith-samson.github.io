HR & Workforce Management

1 application

Subsidiary Directory Manager

Cleaned up First Bank's subsidiary Azure AD directory and became the access-control hub for every other Power Platform app built for the subsidiaries.

Impact: replaced manual Excel tracking with one clean staff repository — full reporting line visible up to line-six supervisor
  • Fixed a subsidiary Active Directory with missing data and poorly mapped job roles by giving HR a bulk (Excel) or single-entry data tool
  • Every HR entry runs through a maker-checker process — one person inputs, another validates and approves
  • Staff can self-onboard: they select their supervisor and fill in missing details, while staff number, email, and name stay locked, pulled directly from AD
  • Self-onboarded records route to the supervisor, then to HR, for final approval
  • Doubles as a security admin console — the security team profiles user access into every other Power Platform app built for the subsidiaries, also under maker-checker control

Cash Status Report

Digitized branch tellers' end-of-day cash counts across three currencies, with automatic routing, approvals, and cross-branch reporting.

Impact: cut chase-for-approval turnaround time by over 80%
  • Replaced paper and Excel-based end-of-day cash counts for Naira, Euro, and Dollar with a single input screen
  • System auto-calculates totals and routes through two levels of approval, notifying a global head once complete
  • Users can pull PDF or Excel reports for one branch and day, or aggregate across custom date ranges and multiple branches at once
  • Used Office Scripts to generate the Excel reports, and XML queries against SharePoint to pull and aggregate the underlying data
  • Automated next-morning reminders flag any pending teller submission or unactioned approval

Legal Budget Tracker

Budget and invoice tracking for the legal team's matters, pulling live invoice approval status straight from SAP Concur.

Impact: ~80% efficiency boost; eliminated manual Excel analysis and manual SAP Concur checks
  • Users create legal matters (matter name, law firm, department, delegated authority, budget) and log quotes (planned spend) and invoices against each
  • A custom connector calls the SAP Concur API daily; once an invoice is approved on SAP, it auto-populates the app's Dataverse tables — no manual lookup needed
  • Tracker view shows actual spend vs. global budget and remaining balance, month by month
  • Invoice list is filterable by status, matter, department, law firm, date range, and aging (e.g. unapproved after 14 days)
  • Power BI dashboard covers matter counts, yearly budgets, spend breakdowns by department and law firm, top-5 matters, and trend/forecast analysis
  • Automated alerts fire at 90% and 100%+ of global budget spend

Value Chain Management

Manages value chain member promotions against an on-prem banking database, with an RPA bot completing the loop back into the core banking system.

  • Built for the value chain team to upgrade value chain members to "principal" status
  • Pulls value chain data through API calls to an on-prem database — Power Apps has no direct line to First Bank's on-prem systems, so the app calls out through an API layer
  • Supports assigning principal roles, deleting or adding value chains, and adding or updating principal records
  • Aggregates every change into an Excel file, which is handed to an RPA bot that applies the updates directly in the on-prem core banking database

Governance & Compliance

2 applications

Change Approval Workflow

Change request system where the approval chain configures itself based on the type of change being submitted.

  • Captures change type, owner, department, product/application, priority, description, reason, impact, assumptions, and attachments in a single form
  • Approval depth adjusts automatically by change type — an IT system support request needs two approval levels, while a defect or enhancement needs three
  • Approvers can approve or reject, and see the full timeline of a request from creation through every approval step
  • Full audit log of every action taken in the app
  • Analytics dashboard breaks requests down by type, status, priority, and how long overdue items have been aging

SpeedyApproval

Memo drafting and multi-tier sign-off application with a custom rich text editor and automated image handling for clean PDF output.

  • Users draft memos with subject, sender/recipient, approver and reviewer fields, plus optional sections like executive summary and vendor selection
  • Memos move through sequential review and approval — each approver acts only after the one before them
  • Two memo types: Basic ends at the final approval; KPEX continues on to FinCon, the CFO, the MD, and Manco members where applicable
  • Built a custom rich text field supporting embedded tables and images
  • Wrote a flow that strips images out of that rich text field, stores them in SharePoint, and swaps in the link — then a second flow that reverses this at sign-off, converting the image back to base64 and reinserting it so a clean PDF can be generated
  • Senior approvers can send a memo back to its initiator, escalate to the MD or CFO, request comments, or invite outside reviewers to comment and attach files

Customer Service

1 application

Customer Complaint / Case Management Solution

Case logging and resolution tracking for customer complaints, wired into live account, transaction, and mandate data.

  • Logs complaints, feedback, inquiries, and service requests for both existing customers and non-customers
  • For an existing customer, entering the account number auto-pulls name, CIF, account type, phone, email, domicile branch, customer group, gender, and date of birth
  • System auto-calculates the resolution turnaround time from the case type — e.g. 8, 24, or 48 hours
  • Resolving team marks cases resolved; the logging team has a 24-hour window afterward to reopen a case if the issue isn't actually fixed
  • Full case history view shows everything that happened on a case, end to end
  • Integrates with three on-prem APIs via custom connectors — customer account details, transaction history, and account mandates
